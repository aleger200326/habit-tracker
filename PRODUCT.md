# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React, TypeScript, Vite; agreed in the implementation plan.

## Users
One person tracking personal habits on desktop and mobile.

## Product Purpose
Create and manage habits, mark scheduled days complete, and see progress over time.

## Capabilities and Constraints
- Full habit CRUD; daily or selected-weekday schedules.
- One yes/no completion per scheduled day, including past dates.
- Dashboard, history calendar, streaks, and analytics.
- Data stays in localStorage on one device; no account or server.
- Public source and deployment on GitHub Pages.

## Brand Commitments
Use the dark purple palette in the user's supplied dashboard reference, adapted to a habit tracker.
