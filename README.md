# Ритм — трекер привычек

Адаптивный личный трекер привычек с дашбордом, календарём истории и аналитикой. Можно создавать, просматривать, редактировать и удалять привычки, выбирать дни недели и отмечать выполнение за текущий или прошлые запланированные дни.

## Запуск

Требуется Node.js 20 или новее и pnpm 9.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite. Проверки: `pnpm test`, сборка: `pnpm build`.

## Данные

Привычки и отметки хранятся в `localStorage` браузера на текущем устройстве. Регистрации и синхронизации нет. Очистка данных сайта в браузере удалит записи.

## Публикация

При отправке изменений в ветку `main` workflow `.github/workflows/deploy.yml` тестирует и собирает приложение, затем публикует `dist` в GitHub Pages. В настройках репозитория Pages источником должен быть выбран **GitHub Actions**. Приложение настроено на путь `/habit-tracker/`.
